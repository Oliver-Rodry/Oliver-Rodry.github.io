Papelería Sol Naciente

Catalog Automation

Herramienta de uso personal del propietario de Papelería Sol Naciente, Oliver Rodriguez. Lee los archivos de inventario enviados a su cuenta de Gmail, actualiza el catálogo de la tienda y envía al propietario un reporte de cambios respecto del inventario anterior.

Los clientes de la tienda no necesitan conectar una cuenta de Google para consultar el catálogo.

Política de privacidad

Acceso y finalidad. La aplicación solicita permiso para leer mensajes y configuración de Gmail y para enviar correo en nombre del propietario. Aunque el permiso de lectura abarca la cuenta, el proceso busca mensajes con archivos de inventario Excel reenviados por el propietario y consulta los reportes enviados para evitar envíos repetidos. No solicita permiso para borrar o modificar mensajes.

Datos utilizados. Procesa el identificador del mensaje, el nombre y contenido del archivo Excel y los campos de productos: código, nombre, descripción, categoría, precio y existencias. Compara inventarios y envía al correo configurado del propietario los cambios y una estimación basada en disminuciones de existencias. No utiliza estos datos para publicidad ni entrenamiento de modelos de IA.

Almacenamiento y divulgación. Google proporciona el correo y la autorización. GitHub Actions ejecuta el proceso; las credenciales se guardan como secretos cifrados del repositorio. Los archivos Excel y reportes se procesan temporalmente durante la ejecución. Los productos se publican en el sitio web y en el repositorio público de la tienda, cuyo historial conserva versiones anteriores. El estado de procesamiento incluye identificadores de mensajes, nombres de archivos, fechas y huellas digitales; los registros de ejecución pueden incluir totales de cambios. Los reportes enviados permanecen en las cuentas de correo correspondientes. Los registros y el correo están sujetos a la retención de GitHub y de los proveedores de correo.

Control del acceso. El propietario puede detener el proceso en GitHub Actions y revocar la conexión en las conexiones de su cuenta de Google. Revocar la conexión impide futuros accesos; no elimina automáticamente el correo, los registros o el historial de inventarios ya publicados. Las solicitudes sobre datos y su eliminación se atienden mediante el contacto indicado abajo; las copias públicas descargadas por terceros no están bajo control de la aplicación.

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de Datos del Usuario de los Servicios de las API de Google, incluidos sus requisitos de Uso Limitado.

Condiciones de uso

Esta aplicación está destinada a la gestión del inventario propio de Papelería Sol Naciente. Solo el propietario debe autorizar su cuenta e introducir archivos que tenga permiso para procesar. Los archivos deben contener exclusivamente la información de productos necesaria para el catálogo.

La actualización depende de que llegue un archivo de inventario válido y de la disponibilidad de Google y GitHub. La estimación del reporte no sustituye los registros de ventas o contabilidad: una reducción de existencias puede deberse a ventas, ajustes u otros movimientos. El propietario debe revisar los datos de origen y corregir cualquier error de inventario.

La aplicación no procesa pagos ni requiere que los visitantes del catálogo concedan permisos de Gmail.
